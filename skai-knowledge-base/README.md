# SKAI База знаний рынка

Прототип интерфейса базы знаний с использованием ИИ для анализа рынка телематических решений.

## Возможности

### Для менеджеров по продажам
- 🔍 **Мгновенное досье по ИНН** - полная информация о компании, парке ТС, текущих продуктах
- 🎯 **Поиск ЛПР** - контакты ключевых лиц и история взаимодействий
- ⚔️ **Сравнение с конкурентами** - ИИ-анализ преимуществ SKAI и слабостей конкурентов
- 📝 **Генератор скриптов продаж** - автоматическое создание скриптов на основе анализа конкурентов
- 🎪 **Интеллектуальная воронка** - автоматический поиск клиентов с большим парком ТС, использующих устаревшие решения
- 💼 **Досье "Вендор vs Интегратор"** - стратегии работы с разными типами конкурентов

### Для РОП и руководителей
- 📊 **Расчет потенциальной выручки** - автоматический расчет на основе парка ТС и потребностей
- 📈 **Аналитика проникновения** - визуализация по сегментам, регионам и компаниям
- 🗺️ **Heat Map регионов** - карта активности конкурентов и проникновения SKAI
- 📉 **Статистика захвата территорий** - визуализация красных зон и голубых океанов
- 🔄 **Мониторинг ухода клиентов** - отслеживание перехода клиентов к конкурентам
- 📋 **Валидация планов** - проверка адекватности планов на основе рыночных данных

### Для маркетологов
- 🎯 **Таргетированные кампании** - формирование списков клиентов по категориям
- 📊 **End-to-end аналитика** - ROI, стоимость лида, конверсия по сегментам
- 🎨 **Позиционирование** - адаптация сообщений на основе слабостей конкурентов
- 🔔 **Мониторинг конкурентов** - автоматические уведомления об изменениях цен и продуктов
- 📈 **Визуализация доли рынка** - динамические дашборды

### Для продукт-менеджеров
- 🎯 **Функциональный бенчмаркинг** - сравнение функций SKAI с конкурентами
- 🔍 **Поиск белых пятен** - функции конкурентов, которых нет у SKAI
- 📋 **Приоритизация бэклога** - рекомендации на основе рыночного спроса
- 🔔 **Мониторинг обновлений** - ИИ-анализ релизов конкурентов
- 🧪 **CustDev исследования** - формирование выборок для интервью

### Для финансовых аналитиков
- 📊 **Прогнозирование выручки** - точные прогнозы на основе парков ТС и рыночных цен
- 💰 **Анализ упущенной выгоды** - расчет потерь в сегментах с лидерами-конкурентами
- 📈 **Сценарный анализ** - моделирование "Что если?" для изменения ценовой политики
- 📉 **Мониторинг доли рынка** - оперативное отслеживание изменений расстановки сил

### Общие функции
- 🤖 **ИИ-анализ** - автоматический анализ компаний с рекомендациями и инсайтами
- 📁 **Загрузка данных** - поддержка CSV файлов с данными о конкурентах и клиентах
- 🗺️ **Карта рынка** - структурированная информация о потенциальных клиентах, конкурентах и партнерах
- 🔄 **Автоматизация CRM** - загрузка данных через ИИ-интерфейс

## Использование

### Основные вкладки

1. **Дашборд** - общая статистика, графики по регионам и сегментам, топ возможности
2. **Компании** - поиск по ИНН, названию, региону с детальной информацией
3. **Воронка** - интеллектуальная воронка приоритетных клиентов с большим парком ТС
4. **Бенчмарк** - функциональное сравнение SKAI с конкурентами, белые пятна, приоритизация бэклога
5. **Регионы** - heat map проникновения конкурентов и SKAI по регионам
6. **Загрузка** - импорт CSV файлов с данными

### Рабочие сценарии

**Менеджер по продажам:**
1. Откройте вкладку "Воронка" для поиска приоритетных клиентов
2. Кликните на компанию для просмотра детального досье
3. Нажмите "Сравнить" для получения аргументов против конкурента
4. Используйте сгенерированный скрипт продаж

**Продукт-менеджер:**
1. Откройте вкладку "Бенчмарк" для анализа функций конкурентов
2. Изучите "Белые пятна" - функции, которые нужно добавить
3. Используйте приоритизацию бэклога для планирования разработки

**РОП:**
1. Просмотрите "Регионы" для анализа активности конкурентов
2. Используйте "Дашборд" для оценки потенциала рынка
3. Анализируйте упущенную выгоду в сегментах с конкурентами

## Расчет потенциальной выручки

Система автоматически рассчитывает потенциальную выручку на основе:
- Парка транспортных средств компании
- Используемых решений конкурентов
- Финансовых показателей компании
- Вероятности внедрения решений SKAI

## ИИ-анализ

Для каждой компании система генерирует:
- Приоритет (высокий/средний/низкий)
- Инсайты о компании
- Рекомендации по работе
- Факторы риска

## Проверка «общая инфа» через Firecrawl

Файл **«SKAI Конкуренты. Список. Второстепенные конкуренты, интеграторы. общая инфа»** содержит колонки: О компании, Местоположение головного офиса, Число филиалов/партнёрской сети, География партнерской сети, Клиенты, География клиентов.

**Как проверять и дополнять данные:**

1. **Firecrawl scrape** — для каждой компании с URL вызвать `firecrawl_scrape` (главная, при необходимости страница «Контакты» / «О компании»).
2. По разметке (markdown) извлечь нужные поля и при необходимости уточнить по «Отчет_об_ошибках_и_изменениях».
3. Обновить CSV вручную или через скрипт `firecrawl_obshaya_info.py`:
   - подготовить JSON с обновлениями (по имени компании и полям);
   - запустить: `python firecrawl_obshaya_info.py --update updates.json`.

Скрипт ищет файл «общая инфа» в `Анализ конкурентов/` относительно корня проекта.
