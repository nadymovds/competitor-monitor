Персональные приглашения на мероприятия

Сценарий для маркетологов и менеджеров по продажам: выбираем клиентов и мероприятие, настраиваем стиль обращения и отраслевые акценты — получаем пачку персонализированных писем для отправки из Outlook.

1. Мероприятие

Описание мероприятия: дата, формат и ключевой акцент.

2. Аудитория

Кого приглашаем: выбор клиентов из базы и базовые фильтры.

3. Стиль и акценты писем

Как будем обращаться и что подчёркивать в тексте.

По имени и отчеству По должности Общее обращение (без имени)
Более официально Нейтрально Менее официально
Для нефтегаза Для FMCG / ритейла Для промышленных компаний

В будущей версии сюда можно будет загрузить CSV‑файл с шаблонами писем по отраслям и стилям обращения. База знаний выберет подходящий вариант для каждого клиента в зависимости от отрасли и выбранных критериев.

4. Превью писем для отправки

Примеры того, что менеджер увидит у себя в Outlook для ручной отправки.

Клиент: ООО «Нефтетранс» · Отрасль: нефтегаз официальный стиль
Приглашение на конференцию «Цифровой автопарк 16 апреля»
Уважаемый Алексей Викторович!

Приглашаем вас принять участие в конференции «Цифровой автопарк 16 апреля», где мы покажем кейсы по снижению потерь топлива и повышению безопасности колонн на опасных маршрутах. Отдельный блок будет посвящён проектам с крупнейшими нефтегазовыми перевозчиками.

Во вложении — официальное письмо‑приглашение с программой мероприятия.

Встреча на конференции «Цифровой автопарк 16 апреля»
Добрый день, Мария!

16 апреля проводим конференцию «Цифровой автопарк» — расскажем, как сети FMCG оптимизируют городскую логистику, снижают простои у магазинов и управляют качеством сервиса в доставке. Будем рады видеть вас и коллег из транспортной службы.

Здравствуйте, Илья!
