# Быстрый старт

## Предварительные требования

- Node.js версии 16 или выше ([скачать](https://nodejs.org/))
- npm (устанавливается вместе с Node.js)

## Установка и запуск

1. **Откройте терминал в папке проекта:**
```bash
cd "c:\Users\y.levalds\Downloads\Анализ конкурентов"
```

2. **Установите зависимости:**
```bash
npm install
```
⏱️ Займет 1-2 минуты

3. **Запустите приложение:**
```bash
npm run dev
```

4. **Откройте браузер:**
- Скопируйте адрес из терминала (обычно `http://localhost:5173`)
- Вставьте в адресную строку браузера
- Нажмите Enter

📖 **Подробная инструкция:** См. файл `ИНСТРУКЦИЯ_ПО_ЗАПУСКУ.md`

## Первое использование

1. **Загрузка данных:**
   - Перейдите на вкладку "Загрузка данных"
   - Перетащите CSV файлы или выберите их через кнопку
   - Нажмите "Загрузить и обработать"
   
   Поддерживаемые файлы:
   - `Конкуренты по категориям итог.csv`
   - `SKAI Конкуренты. Список. Прямые конкуренты, интеграторы (1).csv`
   - `Решения_конкурентов_расширенный_список.csv`

2. **Просмотр аналитики:**
   - Вкладка "Дашборд" показывает общую статистику и графики
   - Визуализация по регионам и сегментам
   - Топ возможности для работы

3. **Поиск компаний:**
   - Вкладка "Компании" для поиска по ИНН, названию, региону
   - Клик по карточке открывает детальную информацию
   - ИИ-анализ с рекомендациями

## Основные возможности

✅ Поиск по ИНН и названию компании  
✅ Автоматический расчет потенциальной выручки  
✅ Визуализация проникновения по сегментам и регионам  
✅ ИИ-анализ с приоритетами и рекомендациями  
✅ Загрузка CSV данных  
✅ Детальная информация о компаниях  

## Структура данных

Приложение автоматически объединяет данные из разных CSV файлов по названию компании и рассчитывает:
- Потенциальную выручку на основе парка ТС
- Приоритет работы с компанией
- Рекомендации по внедрению решений SKAI
