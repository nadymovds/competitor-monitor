# Competitor Monitor — Telegram Mini App

## Установка

```bash
cd webapp
npm install
```

## Разработка

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Переменные окружения

Создайте `.env` файл:

```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```
