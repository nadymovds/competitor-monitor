# Система мониторинга конкурентов и отраслевых новостей

Автоматизированная система для отслеживания изменений на сайтах конкурентов и мониторинга отраслевых новостей с использованием LLM для анализа и категоризации.

## 🎯 Основные возможности

### Мониторинг конкурентов
- ✅ Автоматическое сканирование веб-сайтов конкурентов
- ✅ Мониторинг Telegram-каналов конкурентов
- ✅ Определение и категоризация изменений через LLM
- ✅ Категории: Продукты, Цены, Условия, Новости
- ✅ Генерация PDF-отчетов
- ✅ Группировка конкурентов

### Мониторинг отраслевых новостей
- ✅ Сканирование новостных Telegram-каналов
- ✅ Парсинг новостных веб-сайтов
- ✅ Автоматическая классификация по категориям (LLM)
- ✅ Дедупликация контента
- ✅ Генерация новостных дайджестов
- ✅ Статистика сканирований

### Web-интерфейс
- ✅ Telegram Web App для удобного доступа
- ✅ Единая лента изменений и новостей
- ✅ История сканирований с детализацией
- ✅ Управление конкурентами и источниками
- ✅ Фильтрация по группам, категориям, источникам
- ✅ Настройки категорий и каналов

## 🏗️ Архитектура

Система состоит из следующих компонентов:

1. **Python Backend** - скрипты для сканирования и обработки
   - `monitor.py` - мониторинг конкурентов
   - `news_monitor.py` - мониторинг новостей

2. **Supabase** - PostgreSQL база данных + Auth
3. **React Web App** - пользовательский интерфейс (Vite)
4. **Telegram Bot** - интерфейс управления
5. **GitHub Actions** - автоматизация по расписанию

## 🚀 Быстрый старт

### Требования

- Python 3.11+
- Node.js 18+
- Supabase проект
- Telegram Bot Token
- OpenAI/Groq API ключ

### Установка зависимостей

```bash
# Backend
pip install -r requirements.txt
playwright install chromium

# Frontend
cd webapp
npm install
```

### Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```bash
SUPABASE_URL=https://xxx.supabase.co
SUPABASE_KEY=your_supabase_service_key
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id
GROQ_API_KEY=your_groq_api_key
```

Для фронтенда создайте `webapp/.env`:

```bash
VITE_SUPABASE_URL=https://xxx.supabase.co
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### Запуск

```bash
# Мониторинг конкурентов
python monitor.py

# Мониторинг новостей
python news_monitor.py

# Web-интерфейс (development)
cd webapp
npm run dev
```

## 📅 Автоматизация

Система автоматически запускается по расписанию через GitHub Actions:

- **Конкуренты**: каждый понедельник в 15:30 МСК
- **Новости**: каждый понедельник в 15:00 МСК

## 🗄️ Структура базы данных

### Основные таблицы

**Конкуренты:**
- `competitors` - список конкурентов
- `competitor_urls` - URL для мониторинга
- `changes` - обнаруженные изменения
- `competitor_tg_posts` - посты из Telegram
- `summary_reports` - сводные отчеты

**Новости:**
- `news_channels` - источники новостей
- `news_posts` - новостные посты
- `news_categories` - категории новостей
- `news_digests` - дайджесты (статистика сканирований)
- `news_digest_posts` - связь дайджестов с постами

См. [DATABASE_SCHEMA.md](docs/DATABASE_SCHEMA.md) для полной схемы.

## 🔄 Процесс работы

### Мониторинг новостей

1. **Сканирование** - сбор новых постов из источников
2. **Обработка LLM** - извлечение заголовков, summary, категоризация
3. **Дайджест** - создание статистики сканирования в `news_digests`
4. **Уведомления** - отправка PDF и сводки в Telegram

### Мониторинг конкурентов

1. **Сканирование** - проверка веб-сайтов и Telegram каналов
2. **Определение изменений** - сравнение с предыдущим состоянием
3. **Категоризация** - классификация изменений через LLM
4. **Отчеты** - генерация PDF и уведомления

## 📊 Статистика и отчеты

Система сохраняет подробную статистику каждого сканирования:

- Количество просканированных источников
- Количество найденных изменений/новостей
- Статистика по категориям
- Ошибки и проблемы при сканировании
- PDF-отчеты с визуализацией

## 🔒 Безопасность

- Аутентификация через Telegram
- Ролевая модель доступа (admin/editor/viewer)
- Защищенное хранение API ключей
