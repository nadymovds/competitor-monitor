# Система мониторинга конкурентов, новостей и упоминаний

Автоматизированная система для отслеживания изменений на сайтах конкурентов, мониторинга Telegram-каналов, отраслевых новостей и поиска упоминаний компании с использованием LLM для анализа и категоризации.

## 🎯 Основные возможности

### Мониторинг конкурентов
- ✅ Автоматическое сканирование веб-сайтов конкурентов (еженедельно, четверг 18:00 МСК)
- ✅ Мониторинг Telegram-каналов конкурентов (ежедневно, 09:00 МСК)
- ✅ Обнаружение и категоризация изменений через LLM (Groq / llama-3.3-70b)
- ✅ Категории: Продукты, Цены, Услуги, Новости, Технические, Прочее
- ✅ Отслеживание здоровья конкурентов и URL (счётчик последовательных ошибок)
- ✅ Генерация PDF-отчётов
- ✅ Группировка конкурентов
- ✅ Кэширование контента для быстрого поиска изменений
- ✅ Уведомления в личные чаты и групповые чаты Telegram

### Мониторинг отраслевых новостей
- ✅ Сканирование новостных Telegram-каналов (еженедельно, пятница 09:00 МСК)
- ✅ Парсинг новостных веб-сайтов (с поддержкой CSS-селекторов)
- ✅ Автоматическая классификация по категориям (LLM + уверенность)
- ✅ Дедупликация контента по хешам
- ✅ Генерация новостных дайджестов со статистикой
- ✅ Инлайн-кнопка «Показать посты» для просмотра постов дайджеста прямо в Telegram

### Мониторинг упоминаний
- ✅ Поиск упоминаний бренда через Yandex Search API и Google Custom Search API (еженедельно, понедельник 09:00 МСК)
- ✅ Мониторинг Telegram-каналов на предмет упоминаний
- ✅ Парсинг веб-порталов по CSS-селекторам
- ✅ Анализ тональности (позитивная / нейтральная / негативная) через LLM
- ✅ Дедупликация по URL
- ✅ Настройка поисковых терминов и источников через Web App
- ✅ Чёрный список источников (`mention_ignored_sources`)

### Web-интерфейс (Telegram Mini App)
- ✅ Единая лента изменений и новостей (infinite scroll, фильтры)
- ✅ Экран упоминаний компании с фильтрами по источнику и тональности
- ✅ История сканирований конкурентов и новостей (collapse/expand карточки)
- ✅ Управление конкурентами и источниками
- ✅ Фильтрация по группам, категориям, источникам, датам
- ✅ Настройки: категории, каналы, поисковые термины, источники упоминаний

### Управление и безопасность
- ✅ Система ролей (admin / editor / viewer)
- ✅ Row-Level Security (RLS) в Supabase
- ✅ Аутентификация через Telegram Web App (`initData`)
- ✅ История запросов на сканирование через Telegram Bot

## 🏗️ Архитектура

Система состоит из следующих компонентов:

1. **Python Backend** — скрипты для сканирования и обработки
   - `monitor.py` — мониторинг конкурентов (режимы: `--mode websites` / `--mode telegram`)
   - `news_monitor.py` — мониторинг отраслевых новостей
   - `mentions_monitor.py` — мониторинг упоминаний компании
   - `bot.py` — Telegram Bot (Flask webhook, задеплоен на Render.com)

2. **Supabase** — PostgreSQL база данных + Auth
   - Row-Level Security для защиты данных
   - Управление ролями и доступом

3. **React Web App** — пользовательский интерфейс (Vite)
   - Telegram Mini App
   - Экраны: FeedScreen, ScansScreen, CompetitorsScreen, MentionsScreen, SettingsScreen

4. **Telegram Bot** — уведомления и управление
   - Отправка PDF-отчётов и дайджестов
   - Инлайн-кнопки с пагинацией постов дайджеста
   - Webhook-сервер (Flask + python-telegram-bot ≥20.0)

5. **GitHub Actions** — автоматизация по расписанию
   - Запуск скриптов мониторинга по cron
   - Деплой веб-приложения на GitHub Pages

## 🚀 Быстрый старт

### Требования

- Python 3.11+
- Node.js 20+
- Supabase проект
- Telegram Bot Token
- Groq API ключ (LLM)
- Yandex Search API ключ (для мониторинга упоминаний)

### Установка зависимостей

```bash
# Backend
pip install -r requirements.txt
playwright install chromium

# Frontend
cd webapp
npm install
```

### Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```bash
SUPABASE_URL=https://xxx.supabase.co
SUPABASE_KEY=your_supabase_service_key
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_personal_chat_id
TELEGRAM_GROUP_CHAT_IDS=chat_id_1,chat_id_2   # групповые чаты (через запятую)
GROQ_API_KEY=your_groq_api_key
YANDEX_SEARCH_API_KEY=your_yandex_api_key
YANDEX_SEARCH_FOLDER_ID=your_folder_id
GOOGLE_CSE_API_KEY=your_google_cse_key        # опционально
GOOGLE_CSE_ID=your_google_cse_id              # опционально
NEWS_PERIOD_DAYS=7                             # период для news_monitor.py
```

Для фронтенда создайте `webapp/.env`:

```bash
VITE_SUPABASE_URL=https://xxx.supabase.co
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### Запуск

```bash
# Мониторинг конкурентов — сайты
python monitor.py --mode websites

# Мониторинг конкурентов — Telegram-каналы
python monitor.py --mode telegram

# Мониторинг новостей
python news_monitor.py

# Мониторинг упоминаний
python mentions_monitor.py

# Telegram Bot (webhook-сервер)
python bot.py

# Web-интерфейс (development)
cd webapp
npm run dev
```

## 📅 Автоматизация

Система запускается по расписанию через GitHub Actions:

| Скрипт | Расписание | Cron (UTC) |
|--------|-----------|------------|
| `monitor.py --mode websites` | Каждый четверг, 18:00 МСК | `0 15 * * 4` |
| `monitor.py --mode telegram` | Ежедневно, 09:00 МСК | `0 6 * * *` |
| `news_monitor.py` | Каждую пятницу, 09:00 МСК | `0 6 * * 5` |
| `mentions_monitor.py` | Каждый понедельник, 09:00 МСК | `0 6 * * 1` |

## 🗄️ Структура базы данных

### Конкуренты и мониторинг
- `competitors` — список конкурентов
- `competitor_urls` — URL для мониторинга (веб-сайты и Telegram-каналы)
- `competitor_content` / `url_content` — кэш контента
- `competitor_groups` / `groups` — группировка конкурентов
- `changes` — изменения, обнаруженные на сайтах
- `competitor_tg_posts` — посты из Telegram-каналов конкурентов
- `summary_reports` — сводные отчёты о сканировании
- `scan_results` — детальные результаты сканирования

### Здоровье и контроль
- `competitor_health` — счётчик последовательных ошибок по конкуренту
- `url_health` — здоровье отдельных URL
- `scan_problems` — ошибки при сканировании
- `bot_settings` — управление расписанием через бота
- `scan_requests` — история запросов на сканирование

### Новости
- `news_channels` — источники новостей (Telegram + веб-сайты)
- `news_posts` — новостные посты
- `news_categories` — категории новостей
- `news_post_categories` — классификация постов с уверенностью
- `news_digests` — дайджесты (метаданные сканирования)
- `news_digest_posts` — связь дайджестов с постами

### Упоминания
- `mention_search_terms` — поисковые термины (названия бренда/компании)
- `mention_sources` — источники для мониторинга (TG-каналы, веб-порталы)
- `mention_ignored_sources` — чёрный список источников
- `mention_scans` — история запусков мониторинга упоминаний
- `mentions` — найденные упоминания (уникальные по URL)

### Управление доступом
- `users` — пользователи системы (роли: admin / editor / viewer)

См. [DATABASE_SCHEMA.md](docs/DATABASE_SCHEMA.md) для полной схемы.

## 🔄 Процесс работы

### Мониторинг конкурентов

1. **Сканирование** — проверка веб-сайтов (Playwright) или Telegram-каналов (Telethon)
2. **Определение изменений** — сравнение с кэшированным контентом
3. **Категоризация** — классификация изменений через Groq LLM
4. **Отчёты** — генерация PDF, уведомления в Telegram (личные + групповые чаты)

### Мониторинг новостей

1. **Сканирование** — сбор новых постов из источников
2. **LLM-обработка** — извлечение заголовков, summary, категоризация
3. **Дайджест** — создание записи в `news_digests` со статистикой
4. **Уведомления** — отправка PDF с инлайн-кнопкой «Показать посты»

### Мониторинг упоминаний

1. **Поиск** — Yandex/Google API + Telegram-каналы + веб-порталы
2. **LLM-обработка** — анализ тональности, генерация summary
3. **Сохранение** — дедупликация по URL, запись в `mentions`

## 📱 Руководство пользователя Web App

### Вход в систему

1. Откройте бота в Telegram
2. Нажмите «Открыть приложение» или перейдите по ссылке на Web App
3. Система автоматически проверит доступ через `initData`

### Роли и полномочия

| Роль | Возможности |
|------|-------------|
| **Admin** | Полный доступ, управление пользователями и конфигурацией |
| **Editor** | Редактирование конкурентов и источников новостей |
| **Viewer** | Только просмотр данных |

### Навигация

Снизу экрана — панель с пятью вкладками:

| Вкладка | Иконка | Назначение |
|---------|--------|-----------|
| **Лента** | 📰 | Объединённый поток изменений конкурентов и отраслевых новостей |
| **Сканирования** | 🔍 | История сканирований с результатами и статистикой |
| **Конкуренты** | 🏢 | Управление списком конкурентов и источников |
| **Упоминания** | 💬 | Упоминания компании в интернете и Telegram |
| **Настройки** | ⚙️ | Конфигурация категорий, каналов и параметров |

### Лента (Feed)

Переключатель типа: **Все** / **Конкуренты** / **Новости**

Фильтры для типа **Конкуренты:**
- Группы конкурентов (MultiSelect)
- Тип источника: Все / Сайт / Telegram
- Категория изменений

Фильтры для типа **Новости:**
- Категории, каналы, тип источника

По умолчанию показывает данные за последние 30 дней. Поддерживает бесконечную прокрутку (по 10 элементов) и кнопку «↑» для возврата вверх.

### Сканирования (Scans)

Переключатель: **Конкуренты** / **Новости**. Карточки с collapse/expand и lazy-loading деталей. Отображает ближайшее запланированное сканирование.

### Упоминания (Mentions)

Фильтры: по источнику (Яндекс / Google / Telegram / Портал), тональности (🟢 Позитивные / ⚪ Нейтральные / 🔴 Негативные), периоду.

### Настройки (Settings)

- **Категории** — настройка названий и цветов категорий изменений/новостей
- **Новостные каналы** — управление источниками (Telegram + веб-сайты с CSS-селекторами)
- **Упоминания** (только Admin) — поисковые термины, источники, чёрный список
- **Пользователи** (только Admin) — управление ролями

## ❓ Часто задаваемые вопросы

**Как часто обновляются данные?**
- Изменения конкурентов (сайты): раз в неделю (четверг 18:00 МСК)
- Изменения конкурентов (Telegram): ежедневно (09:00 МСК)
- Новости: раз в неделю (пятница 09:00 МСК)
- Упоминания: раз в неделю (понедельник 09:00 МСК)

**Как добавить нового конкурента?**
Вкладка Конкуренты → «+ Добавить конкурента». Требуется роль Editor или Admin.

**Как настроить отслеживание упоминаний?**
Вкладка Настройки → раздел «Упоминания». Требуется роль Admin.

**Почему нет данных за сегодня?**
Данные обновляются по расписанию. Если сканирование ещё не произошло, новых данных не будет.

**Приложение не открывается?**
- Убедитесь, что авторизованы в Telegram
- Попробуйте перезагрузить страницу
- Обратитесь к администратору для проверки доступа
