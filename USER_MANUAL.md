## 🚀 Начало работы

### Требования доступа

- Приглашение от администратора системы
- Учетная запись Telegram


### Вход в систему

1. Откройте бота в Telegram
2. Нажмите кнопку "Открыть приложение" или перейдите по ссылке на Web App
3. Система автоматически проверит ваш доступ
4. Если доступ разрешен, вы попадете в основное приложение

### Роли и полномочия

Система использует несколько уровней доступа:

- **Admin** - полный доступ, управление пользователями и конфигурацией
- **Editor** - редактирование конкурентов и источников новостей
- **Viewer** - просмотр данных без возможности изменений

## 📰 Вкладка Лента (Feed)

Это главная страница всех изменений и новостей в едином потоке.

### Основные элементы

Каждый элемент в ленте отображает:

- **Источник** - откуда поступила информация (конкурент, новостной канал)
- **Заголовок** - название изменения или новости
- **Описание** - краткое содержание
- **Категория** - тип информации (Продукты, Цены, Услуги, Новости, Акции, Прочее)
- **Дата** - когда было обнаружено изменение или опубликована новость
- **Статус** - прочитано/не прочитано (для новостей)

### Типы предметов

#### Изменения конкурентов
- Содержат информацию об изменениях на сайтах или Telegram-каналах конкурентов
- Отмечены значком конкурента или логотипом
- Сгруппированы по группам конкурентов

#### Отраслевые новости
- Собраны из новостных Telegram-каналов и веб-сайтов
- Помечены как новость
- Содержат информацию о процентилях популярности

### Переключение типов ленты

Над лентой находится переключатель, позволяющий выбрать:

- **Все** - информация о конкурентах + отраслевые новости
- **Конкуренты** - только информация об изменениях конкурентов
- **Новости** - только отраслевые новости

### Прокрутка и загрузка

- Лента поддерживает **бесконечную прокрутку**
- При приближении к концу автоматически загружаются новые элементы
- Кнопка "Вверх" ↑ помогает быстро вернуться в начало ленты

### Взаимодействие с элементами

- **Нажатие на элемент** - открывает полную информацию об изменении
- **Для конкурентов** - показывает деталь на сайте конкурента
- **Для новостей** - показывает исходный пост или статью

## 📊 Вкладка Сканирования (Scans)

Здесь вы можете просмотреть историю всех сканирований системы.

### Типы сканирований

#### Сканирования конкурентов
- Показывают результаты проверки веб-сайтов и Telegram-каналов
- Содержат информацию о найденных изменениях

#### Сканирования новостей
- Показывают результаты новостных источников
- Содержат статистику по категориям
- Отображают количество найденных новостей и статьи

### Расписание автоматических сканирований

- **Конкуренты** — каждый четверг в **18:00 МСК**
- **Новости** — каждую пятницу в **09:00 МСК**

В разделе отображается ближайшее запланированное сканирование для выбранного типа.

### Информация , отображаемая для каждого сканирования

| Поле | Описание |
|------|---------|
| **Дата и время** | Когда было проведено сканирование |
| **Статус** | успешно/ошибка |
| **Тип** | конкурент/новости |
| **Количество результатов** | Сколько элементов найдено |
| **Деталь** | Ссылка на подробную информацию |

### Фильтрация сканирований

По умолчанию отображаются последние сканирования. Вы можете отфильтровать по:
- **Типу** - конкуренты или новости
- **Дате** - выбрать диапазон дат
- **Источнику** - конкретному конкуренту или каналу



## 🏢 Вкладка Конкуренты (Competitors)

Управление списком конкурентов, их источников и группировок.

> **Примечание:** Полный доступ (редактирование/удаление) доступен только администраторам и редакторам.

### Структура данных

#### Группы конкурентов
- Конкуренты организованы в группы для удобства классификации
- Примеры: "Прямые конкуренты", "Косвенные конкуренты", "Потенциальные партнеры"
- Фильтрация в ленте по группам

#### Информация о конкуренте

Каждый конкурент содержит:

| Поле | Описание |
|------|---------|
| **Имя** | Название компании или конкурента |
| **Группа** | Категория в системе |
| **Веб-сайт** | URL главной страницы (если монитируется) |
| **Telegram канал** | Ссылка на Telegram-канал (если продолжается мониторинг) |
| **Активен** | Включены ли сканирования для этого конкурента |

### Просмотр изменений конкурента

1. Нажмите на конкурента в списке
2. Откроется список всех обнаруженных изменений для этого конкурента
3. Нажмите на изменение để просмотреть подробности
4. Если изменение связано с сайтом - можете увидеть скриншот или содержимое

### Добавление нового конкурента (для Editors/Admins)

1. Нажмите кнопку "+ Добавить конкурента"
2. Заполните информацию:
   - Имя конкурента
   - Выберите группу
   - Добавьте веб-сайт (если требуется)
   - Добавьте Telegram канал (если требуется)
3. Сохраните

> Система автоматически добавит конкурента в очередь сканирования.

### Управление группами (для Admins)

1. В настройках найдите раздел "Группы конкурентов"
2. Добавьте новую группу или отредактируйте существующую
3. Сохраните изменения

## 🔧 Вкладка Настройки (Settings)

Конфигурация системы и управление параметрами.

### Разделы настроек

#### 1. Категории

Настройка категорий для классификации изменений и новостей:

- **Продукты** - новые продукты, обновления, прекращение
- **Цены** - изменения стоимости, тарифы, скидки
- **Услуги** - новые услуги, трансформация предложения
- **Новости** - корпоративные новости, пресс-релизы
- **Акции** - рекламные компании, специальные предложения
- **Прочее** - все остальное

Для каждой категории можно:
- Изменить название
- Изменить цвет для визуального различия
- Включить/отключить для новых элементов

#### 2. Новостные каналы

Управление источниками новостей:

| Параметр | Описание |
|----------|---------|
| **Имя канала** | Название источника |
| **Тип** | Telegram канал или веб-сайт |
| **URL/ID** | Адрес сайта или ID Telegram канала |
| **Селекторы (для веб)** | CSS-селекторы для парсинга |
| **Последнее сканирование** | Когда был проверен канал |
| **Активен** | Включен ли мониторинг |

## 🔍 Фильтрация и поиск

### Фильтры в ленте

Нажмите на кнопку "Фильтры" в верхней части ленты:

```
Фильтры доступные:
├── Группы конкурентов
│   ├── Прямые конкуренты
│   ├── Косвенные конкуренты
│   └── Прочие
│
├── Категории
│   ├── Продукты
│   ├── Цены
│   ├── Услуги
│   ├── Новости
│   ├── Акции
│   └── Прочее
│
├── Источники
│   ├── [Список конкурентов]
│   └── [Список новостных каналов]
│
└── Период
    ├── Последний день
    ├── Последняя неделя
    ├── Последний месяц
    └── Пользовательский диапазон
```

### Применение фильтров

1. Откройте меню фильтров
2. Выберите нужные параметры (можно выбрать несколько)
3. Нажмите "Применить"
4. Лента обновится только нужными элементами

### Очистка фильтров

- Нажмите "Очистить все" в меню фильтров
- Или нажмите X рядом с активным фильтром
